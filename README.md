The Weather Forecast App is a user-friendly application designed to provide accurate and up-to-date weather information for any location. It helps users stay informed about current weather conditions and future forecasts, enabling them to plan their daily activities effectively.

The app displays essential weather details such as temperature, humidity, wind speed, atmospheric pressure, visibility, and chances of rainfall. It also offers daily and weekly forecasts, allowing users to prepare for changing weather conditions. The application retrieves real-time weather data from online weather APIs and presents it through an attractive and easy-to-understand interface.

  This is a code bundle for Weather Forecast App. The original project is available at https://www.figma.com/design/Soc6KFE8LjobAU5keq0eDh/Weather-Forecast-App.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
